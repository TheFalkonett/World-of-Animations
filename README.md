# World of Animations (WoA)

*World of Animations* (WoA) is a modding project for *World of Tanks* focused on bringing vehicles to life through animated components and mechanical detail.

Originally started in 2017 as the **UML Utilization Project (UUP)**.

## Features

* Animated vehicle components
* Modular `.wotmod` packages
* Lightweight integration

Examples include, but are not limited to:

* Cupolas
* Optics
* Periscopes
* Miniturrets
* Antennas
* Cables
* Bushes
* Buckets!!
* Decorative moving parts

## Compatibility

World of Animations modifies the 3D models, and on rare occassion the AO texture.
Therefore the following mods will be incompatible:
* Mods that affect the 3D model of a tank (remodels)
* Mods that affect the `AO` texture of a tank (e.g. "Clean Camo" by Gravity_Assist)

2D skins however (as long as they don't affect the `AO` texture) will be compatible.

## Installation

Ensure [UML](https://wgmods.net/6776/) is installed.

WoA can be installed either:

* through the official [installer](https://wgmods.net/561/).
* by cloning this repository in your `mods\$version` folder (this also allows updating via `git pull`).
* manually, by downloading the `.wotmod` files and placing them in the latest `mods\$version` folder.
  * Ensure that `WoA_SharedTextures.wotmod` is also installed.
